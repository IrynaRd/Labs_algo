## Лабораторні роботи з дисципліни "Алгоритмізація та програмування"

## Виконала: Рудницька Ірина Іванівна (ІР-14)
## Лабораторна робота №7 (Варіант 20 (5))
Відновлення кроків гри: Гравець
може відкататися назад на кілька
кроків для виправлення помилок.
Посадка пасажирів на
автобусній зупинці: Пасажири
сідають у автобус у порядку
свого прибуття.
